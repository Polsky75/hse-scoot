# hse-scoot

Консольное приложение сервиса кикшеринга: загружает инвентарь, проводит
техосмотр нового транспорта и ставит его на учёт, затем считает вещи
на учёте и выводит отчёт в консоль или файл.

В инвентаре есть транспорт (самокаты, велосипеды, электровелосипеды)
и снаряжение (шлемы, наколенники, зарядные станции). У каждой вещи есть
инвентарный номер и категория.

## Запуск

```sh
# файловый режим, отчёт в консоль
go run .

# интерактивный ввод без файла
go run . -interactive

# отчёт в файл
go run . -report file -report-path report.txt

# другой файл инвентаря
go run . -devices data/devices.txt
```

Флаги:

- `-devices` — путь к текстовому файлу инвентаря (по умолчанию
  `data/devices.txt`);
- `-report` — способ вывода: `console` или `file` (по умолчанию `console`);
- `-report-path` — путь к файлу при `-report=file`;
- `-interactive` — ввод данных в консоли без файла.

## Интерактивный режим

```sh
go run . -interactive
```

Меню:

- `1` — добавить вещь, уже стоящую на учёте (сначала выбирается
  транспорт или оборудование);
- `2` — поставить транспорт на учёт;
- `3` — поставить оборудование на учёт;
- `0` — завершить и вывести отчёт.

Для транспорта и оборудования показываются отдельные нумерованные списки
видов. При неверной цифре или формате ввода выводится сообщение и запрос
повторяется. Инвентарный номер можно ввести вручную или нажать Enter,
чтобы присвоить следующий автоматический. В номере допустимы только
заглавные латинские буквы, цифры и тире; иначе выводится ошибка и запрос
повторяется. Результат и присвоенный номер показываются сразу после
обработки. Файловый режим остаётся режимом по умолчанию.

## Отчёт

Отчёт содержит счёт вещей и три списка:

- всё оборудование (вещи, не являющиеся транспортом);
- весь транспорт;
- транспорт, подходящий новичкам.

У каждой строки указаны инвентарный номер и категория. Счёт включает
все вещи, транспорт, оборудование, самокаты, наколенники и суммарное
суточное потребление энергии

```text
hse-scoot — отчёт по инвентарю

Всего вещей на учёте: 8
Транспорт: 5
Оборудование: 3
Самокаты: 2
Наколенники: 1
Суммарное суточное потребление: 7.55 кВт·ч

Всё оборудование (3):
  HELMET-001 — шлем
  KNEE-001 — наколенники
  STATION-001 — зарядная станция

Транспорт (5):
  ...

Транспорт для новичков (3):
  SCOOT-001 — самокат
  BIKE-001 — велосипед
  SCOOT-004 — самокат
```

Перед отчётом в консоль выводится служебный статус постановки на учёт,
включая отклонённые техосмотром устройства.
